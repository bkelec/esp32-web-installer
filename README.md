# ESP32 Web Installer

เว็บสำหรับเลือกสินค้าและติดตั้งเฟิร์มแวร์ ESP32 ผ่านสาย USB ด้วย Chrome หรือ Edge

## การเพิ่มสินค้าและเฟิร์มแวร์

1. เพิ่มไฟล์ `.bin` ของสินค้าใหม่ในโปรเจกต์
2. สร้าง manifest ใหม่ โดยระบุ `chipFamily`, path และ offset ให้ตรงกับเฟิร์มแวร์
3. เพิ่มรูปสินค้าในโฟลเดอร์ `images`
4. เพิ่มข้อมูลสินค้าในตัวแปร `products` ที่ท้ายไฟล์ `index.html`

แต่ละสินค้าควรใช้ manifest แยกกัน เพื่อป้องกันการเลือกไฟล์ผิดรุ่น
