# ESP32 Web Installer

เว็บสำหรับเลือกสินค้าและติดตั้งเฟิร์มแวร์ ESP32 ผ่านสาย USB ด้วย Chrome หรือ Edge ชื่อรุ่นจะแสดงตามชื่อไฟล์เพื่อแยกสินค้าที่ใช้รูปเหมือนกัน

## การเพิ่มสินค้าและเฟิร์มแวร์

1. เพิ่มไฟล์เฟิร์มแวร์ merged `.bin` ที่รวม bootloader, partition table และแอป พร้อมไฟล์ `.jpg` ที่มีชื่อหลักตรงกันในโฟลเดอร์ `source`
2. สร้าง manifest ใหม่ในโฟลเดอร์ `manifests` โดยใช้ `chipFamily` เป็น `ESP32` และ offset `0` (`0x0`) สำหรับไฟล์ merged ที่สร้างให้เริ่มแฟลชที่ `0x0` เช่นไฟล์ปัจจุบันทั้ง 3 รุ่น หากสร้างไฟล์ด้วย target offset อื่น ต้องกำหนด offset ให้ตรงกัน
3. เพิ่มข้อมูลสินค้าในตัวแปร `products` ที่ท้ายไฟล์ `index.html`

แต่ละสินค้าใช้ manifest แยกกัน และปุ่มติดตั้งจะแสดงชื่อรุ่นที่เลือกเพื่อป้องกันการเลือกเฟิร์มแวร์ผิดรุ่น
